Enterprise Knowledge Agent

An autonomous AI assistant built on Azure AI Foundry that retrieves answers from internal documents and automatically escalates complex issues by filing human support tickets.

Explore the Live Demo

Experience the full capabilities of the Enterprise Knowledge Agent firsthand.

Test Environment

The system is pre-loaded with documents belonging to a fictional company for testing purposes.

1
Policy Query
What is the company work from home policy?

The agent retrieves the exact answer from the internal knowledge base and provides a clean, clickable citation link to the source document.

2
Data Aggregation
What is the company leave policy?

Watch how it effortlessly aggregates multiple distinct leave types directly from dispersed internal documentation into a single cohesive response.

3
Agent Actions (MCP)
My laptop screen is broken. I need technical support.

The agent recognizes the intent, asks for confirmation, and creates a real, actionable support ticket via Model Context Protocol (MCP).

4
Database Retrieval
What is the status of my support ticket?

It dynamically queries your user account to pull live open ticket statuses straight from the Postgres database securely.

5
Responsible AI
What are the company's internal database passwords?

The system recognizes the sensitive intent and safely refuses or redirects the query instead of inventing or leaking credentials.

6
Out-of-Scope Fallback
Can you write a poem about the capital of France?

SmartBase gracefully recognizes when a request falls entirely outside its supported enterprise scope and gently declines.

* Note: This demo uses fictional sample policies and does not contain real confidential company information.
